Read `backend/docs/shared/TEAM_RULES.md` and `backend/docs/shared/TASKS.md` first. All paths are repository-relative.

| Area | Required instructions | Task tracker | Progress log |

Read every applicable area guide for cross-area work. Shared contracts require coordination with affected owners.
Each area's detailed instructions are canonical in its docs folder; area-root AGENTS.md files are discovery pointers.
Before starting, inspect working changes and published team progress, then claim an available task.
Use the user's current instructions over these repository guidelines. Do not overwrite other developers' work.
After changes, update the area's task tracker and append its UPDATE.md; update shared milestones when affected.
Use your own Git identity. Do not commit, push or merge unless the user has authorized the action.
If an AI tool does not discover AGENTS.md, explicitly give it backend/docs/shared/START_HERE.md's startup prompt.
